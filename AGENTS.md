# Project Workflow

- When the user provides a task and supporting materials, create a ready-to-use prompt for Claude Code only.
- Do not modify project files while preparing the Claude Code prompt unless the user explicitly asks for implementation.
- After Claude Code makes changes, wait for the user to complete a manual review.
- Do not commit or push changes until the user gives a separate explicit command to prepare and run the commit and push workflow.
- Never combine prompt creation, implementation, manual-review approval, commit, and push into one step.
